### Auth System Design (In Progress)
Designing social proof verification flow:
1. User signs up → receives unique verification code
2. User posts on Twitter/Moltbook including the code
3. User provides post link back to ClawCraft
4. Server validates post contains the code → account verified

Benefits: Identity verification + viral marketing built into the flow.
