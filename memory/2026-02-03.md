## New Project: BitPix 🎨

**ClawCraft on hold.** Started brainstorming a new project with Khelil.

### The Idea
**BitPix** — "The TouchDesigner of pixel art"

A browser-based, node-based generative tool for creating live pixel art visuals. Think live coding music (Sonic Pi, TidalCycles), but for lo-fi visuals.

### Key Decisions
- **Platform:** Browser-based
- **Target users:** Game devs, artists, VJs — all of them
- **Focus:** Live performance, like live coding music
- **Name:** BitPix

### Tech Stack
- TypeScript + Vite
- LiteGraph.js (node editor)
- Canvas 2D (rendering)
- 64x64 pixel buffer (scaled up)

### Scaffolded Today

**Project structure:**
```
bitpix/
├── src/
│   ├── core/
│   │   ├── PixelBuffer.ts    # Core RGBA buffer class
│   │   ├── Palette.ts        # Classic palettes (PICO-8, Game Boy, etc.)
│   │   └── Noise.ts          # Simplex noise implementation
│   ├── nodes/
│   │   ├── NoiseNode.ts      # Simplex noise generator
│   │   ├── ColorNode.ts      # Solid color + gradient
│   │   ├── OscillatorNode.ts # Animation (sine, saw, square, triangle)
│   │   ├── BlendNode.ts      # Compositing (mix, add, multiply, screen, overlay)
│   │   ├── EffectsNode.ts    # Palette quantize, pixelate, threshold, invert
│   │   └── OutputNode.ts     # Final render output
│   └── main.ts               # App entry point
├── package.json
└── README.md
```

**Node types implemented:**
- Generators: Noise, Color, Gradient
- Animation: Oscillator, LFO (BPM-synced)
- Effects: Palette, Pixelate, Threshold, Invert
- Compositing: Blend, Mask
- Output: Display

**Default graph:**
Oscillator → Noise (drives scale) → Palette (PICO-8) → Output

## Save/Load System Implemented ✅

**Files:**
- `src/core/SaveLoad.ts` — Full serialization/preset/URL system
- Updated `main.ts` — UI integration
- Updated `index.html` — New toolbar buttons
- Updated `main.css` — Styled controls + toast notifications

**Features:**
- **💾 Save** — Save current graph to localStorage with custom name
- **📂 Preset dropdown** — Quick load from saved presets
- **🗑️ Delete** — Remove presets
- **📄 New** — Clear graph
- **📁 Load** — Import .json file from disk
- **🔗 Share** — Copy URL with graph encoded in base64 (auto-loads on visit)
- **Keyboard shortcuts:** Ctrl+S (save), Ctrl+O (load file), Ctrl+Shift+S (download)
- **Toast notifications** — Visual feedback on actions
- Built-in preset stubs (🌊 Plasma, 🔥 Fire, 🌈 Rainbow) — ready to populate
