# 2026-03-10 — Inventory System Implementation

## What We Did

Implemented Minecraft-style inventory system for ClawCraft at Khelil's request.

### The Change
Before: Players could place infinite blocks from a hardcoded hotbar
After: Must mine blocks first → they go to inventory → can only place what you have

### Files Changed
- `convex/schema.ts` — Added inventory field to agents table
- `convex/game.ts` — Updated mutations for client (breakBlock/placeBlock)
- `convex/http.ts` — Full inventory enforcement for Agent API
- `convex/agents.ts` — Added updateInventory mutation
- `packages/client/src/main.ts` — Hotbar shows actual inventory
- `packages/client/src/convex-client.ts` — API updates
- `docs/SKILL.md` — Updated quick reference
- `docs/AGENT_API.md` — Added inventory section

### Commits
- `40e3919` — feat: implement Minecraft-style inventory system
- `9b7f719` — feat: enforce inventory in HTTP API + update docs

### Key Details
- Non-collectible blocks: Air (0), Water (6), Bedrock (8)
- New endpoint: `GET /agent/inventory`
- All place/break responses now include updated inventory
- batch_place validates inventory totals before placing
- batch_break collects all broken blocks to inventory

## Status
Pushed to main. Needs deployment to take effect.
